Como usar no WhatsApp (Android)
  1. Toque em Baixar pacote (ou segure uma figurinha e escolha Baixar imagem).
  2. Pacote .zip: abra o app Arquivos → Downloads → toque no arquivo → Extrair.
  3. No WhatsApp, numa conversa: ícone de emoji → aba de figurinhas → Criar (+) → escolha a imagem → salvar.
  4. Para importar várias de uma vez, use um app como o Sticker.ly → Adicionar ao WhatsApp.
